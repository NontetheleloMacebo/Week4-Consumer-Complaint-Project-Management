# Consumer Complaint Trends and Response Intelligence Platform

**AnalystLab Africa | Experience Lab | Week 4 | Batch F**  
**Project Management Track**

## Project Overview

This project focuses on the planning and coordination of a Consumer Complaint Trends and Response Intelligence Platform using consumer complaint data from the Consumer Financial Protection Bureau (CFPB).

The Project Management track covers project initiation, planning, scheduling, stakeholder management, risk management, project monitoring, coordination and reporting.

The project brings together five workstreams:

- Project Management
- Data Analytics
- Data Science
- Machine Learning
- Generative AI

## Dataset Overview

The project uses CFPB consumer complaint data covering the period **1 May 2017 to 28 August 2023**.

The dataset contains complaint information, including submission dates, products, issues, companies and company responses.

The following interpretation points are important:

- Date submitted refers to the date the CFPB received the complaint.
- Date received refers to the date the CFPB sent the complaint to the company.
- The difference between these dates represents the complaint-forwarding interval, not the company's response or resolution time.
- Blank timely-response values should not automatically be interpreted as "No".
- A complaint record does not, on its own, establish misconduct or a regulatory breach.
